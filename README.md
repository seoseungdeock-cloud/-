# 라잇나우 통합앱 (뼈대)

의뢰인과 변호사가 함께 쓰는 법률 서비스 앱의 첫 뼈대입니다. 하나의 앱 안에 다섯 기능이 들어 있습니다.

| 기능 | 위치 | 지금 되는 것 |
|---|---|---|
| 메신저 | 대화 탭, `src/app/room` | 1:1·단체·새로운 사람·사무소·회의·마케팅방, 암호화방/AI 참여방 구분과 표시, `@AI` 호출 |
| 사건방 | 사건 탭 | 상담방 → (본인확인 후) 사건방 전환, 진행·기일·서류·비용 공유 |
| 변호사 지도 | 찾기 탭 | 대한민국 시·도 지도, 지역·분야·검색·정렬(고객 선택), 상담 신청 |
| 경영 에이전트 | 업무 탭 (어드민 허용자만) | 회의 정리(녹음 동의 포함), 지난 결정 기반 의견, 자료 이미지 재생성, 프로그램 요청 |
| 마케팅 AI | 업무 탭 → 마케팅 AI | 명령 → 계획 → 승인 → 실행(예산 한도), 광고 규정 점검, 유사도, 성과 순위 |
| 라잇나우 멤버십 | 나 탭 | 멤버 혜택 화면 (플랫폼 자체 서비스만) |

## 설계 원칙

- **모든 것이 "방"**: 사건방·사무소방·회의방·마케팅방이 같은 구조이고, AI는 방에 들어오는 참여자입니다.
- **방의 보안 방식은 만들 때 정하고 바꿀 수 없음**: 암호화방(🔒)은 AI·운영자가 읽지 못하고, AI 참여방(✦)은 상단에 항상 표시됩니다.
- **이중 신원**: 평소엔 닉네임. 사건방 입장 때만 본인확인, 모르는 사람과의 대화는 성인인증.
- **AI 답변 수준**: 변호사가 없는 방에서는 일반 법률 정보만 안내합니다 (변호사법 109조).
- **변호사 목록 정렬은 고객이 고름**: AI 추천·광고비 순위 없음. 상담료만 표시하고 수임료는 표시하지 않습니다.

## 아직 연결하지 않은 것 (요청 시 연결)

서버·DB, 실제 AI 모델, 음성인식, 본인확인(PASS 등), 결제, 광고 계정 API, 푸시 알림.
지금은 모든 데이터가 기기 메모리에만 있어 앱을 다시 열면 처음 상태로 돌아갑니다.

연결 지점:
- AI: `src/core/ai.ts` 의 `AiProvider` 를 구현해 `setAi()` 로 넣으면 모든 `[AI 미연결]` 자리가 실제 답변으로 바뀝니다.
- 서버: `src/core/store.ts` 의 `actions` 를 API 호출로 바꾸면 화면 코드는 그대로 둘 수 있습니다.
- 메신저 엔진: 서버를 붙일 때 Matrix 프로토콜(종단간 암호화, 봇 참여 지원)을 권장합니다.

## 법대륜 데이터 넣기

지금 지도에는 `sample: true` 샘플 4곳만 있습니다. CSV를 받으면:

```bash
node scripts/import-offices.mjs 법대륜.csv   # src/data/offices.json 을 덮어씁니다
```

CSV 머리글: `사무소명,시도,주소,전화,위도,경도,변호사명,분야,경력,상담료` (한 줄에 변호사 한 명, 분야는 `;`로 구분).

## 실행

```bash
npm install
npx expo start        # 휴대폰 Expo Go 또는 w 키로 웹에서 보기
npm test              # 핵심 규칙 테스트
npm run typecheck
```

나 탭의 "다른 사용자로 보기"에서 어드민·직원·변호사·의뢰인 화면을 바꿔 볼 수 있습니다.

## 폴더

```
src/app/      화면 (Expo Router: 파일 하나가 화면 하나)
src/core/     규칙과 상태 (화면 없이 테스트 가능)
src/ui/       공통 부품, 디자인 토큰, 지도·차트
src/data/     지도 경로, 사무소 데이터
scripts/      지도 생성, 사무소 CSV 가져오기
```

지도 경계 원본: [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps) (KOSTAT 2013), `scripts/build-korea-map.mjs` 로 변환.
